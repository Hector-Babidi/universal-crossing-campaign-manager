# Universal Crossing Campaign Manager

Sistema de gerenciamento de campanhas de RPG baseado no sistema Universal Crossing v3.4.

## Funcionalidades
- Fichas de personagens
- Atributos e perícias
- Cálculo automático de status
- Sistema de experiência (XP)
- Inventário e equipamentos
- Acesso de jogadores para visualização
- Edição exclusiva do mestre

## Tecnologias
- Next.js
- Supabase
- Vercel
